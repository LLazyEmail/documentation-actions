# Agent checklist: short names

When writing or updating a caller:

1. Check `docs/naming.md` for an alias.
2. Prefer the short name in `uses:`.
3. Keep triggers and permissions on the caller.
4. Pin `@v2` (or a SHA) after release.
5. Do not invent new long names.

## Available short names

- `reusable-pages-deploy`
- `reusable-test-deploy`
- `reusable-readme-sync`
- `reusable-readme-only`
- `reusable-label-conflicts`
- `reusable-pr-report`
- `reusable-thin-content`
- `reusable-image-check`
- `reusable-entry-format`
- `reusable-sync-feedback` (new, no long name)

Both long and short names work. New code should use short names.
